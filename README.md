# OverGrow Themes

Community worlds for [OverGrow](#待填：App Store 链接) — a macOS menu bar app that grows grass on your desktop when you've been staring too long.

Each `.overgrowpack` in this repository is a complete desktop scene: palette, weather, wildlife and rest screen, matched.

## Browse & install

1. Open the [gallery discussion](https://github.com/LoxoTechIO/OverGrow-Theme/discussions/categories/theme-gallery) or the list below.
2. Download the `.overgrowpack` file you like.
3. Double-click it (or drag it onto OverGrow's settings window). Done — it appears in Settings → Worlds.

You can preview any world for 5 minutes before deciding. Themes from the gallery are community-made and licensed by their authors (see each theme's post).

## Submit your world

We review submissions continuously. Picked themes get permanent credit in this repository and a free copy of OverGrow.

[Open a theme submission →](../../issues/new/choose)

Requirements, in short:

- Original work, or assets you have the right to share. Credit photographers and sources.
- One pack per issue. Include a short description and at least one screenshot.
- No copyrighted material you don't own; no AI-only bundles with claimed authorship of underlying photos you can't license.
- Files must pass the app's built-in validation (OverGrow will tell you if anything is off).
